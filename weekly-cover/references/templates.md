# 封面模板规格

三个模板的图层 ID 是从母版 PSD 直接 inspect 得到，用于 JSX 引擎。
`box` 是 CG 智能对象替换后的目标矩形（画布像素坐标），渲染引擎按
cover 适配该矩形并居中。

## T2 校色

T2 母版底为紫粉渐变。`refine` 对这些图层做色相 -90、饱和 -30、明度 +8：
`1340`、`1226`、`920`，并把纯色填充层 `1247`、`1013` 改为 CG 边缘主色。

## 人脸安全几何说明

T3 默认目标框为 `[0, 0, 2400, 1800]`，使用 cover 将素材等比放大并裁切填满
整个 4:3 画布。16:9 素材会超出左右边缘；不得改用 contain 留出上下空带，
也不得非等比拉伸。

若人脸被右上「VOL」标题遮挡，可在本批次 `job.json` 中平移两个替换层的
目标框，再执行 render；不要修改母版。平移后实际素材边界仍须覆盖画布四边。
第267期素材向左平移400px（目标框 `[-400, 0, 2000, 1800]`）可避开眼睛；
这是该素材的构图选择，不作为其他素材的固定偏移。
