# 口播日文注音规范与补漏指南

## 一、注音范围与语言判断

1. **英文借词还原**：用日语片假名拼写的英文单词或短语，优先还原为准确英文（使用 VNDB 官方名或常见英文拼写），例如：
   - `《セレクトオブリージュ》【Select Oblige】`
   - `きゃべつそふと【Kyabetsusofuto】` 或官方英文写法
   - `あじゅ～るメモリア【Azure Memoria】`
2. **保留日语发音**：含假名（平假名、片假名或汉字+假名混合）的作品名、社团名、人名，紧跟在词后用 `【】` 标注罗马音或官方英文名，例如：
   - `あざらしそふと【Azarashisofuto】`
   - `綾瀬はづき【Ayase Hazuki】`
   - `《早咲きのくろゆり》【Hayazaki no Kuroyuri】`
3. **纯汉字日本人名默认豁免**：如 `新島夕`、`杉田智和`、`西田一` 这类全汉字人名，配音员通常直接按中文汉字读音朗读，默认不强制注音（仅在 `ruby_pairs.json` 显式指定或 VNDB 命中且确需辅助时才标注）。
4. **纯英文/ASCII 标题不重复注音**：例如 `《Happy Weekend》`、`《Luster piece》` 本身已是拉丁字母，不加多余 `【】`。

---

## 二、1:1 安全回写红线

1. **位置规则**：
   - 带书名号的作品/曲名：`《作品名》【Romaji】`（**`【】` 必须紧贴在右书名号 `》` 外侧，严禁插进 `《》` 内部**）。
   - 普通词条（社团、人名、专有名词）：`原词【Romaji】`。
2. **绝不改动正文文字**：将 `口播注音稿.md` 中所有 `【...】` 剔除后，必须能 1:1 无损还原回未注音底稿（`verify` 会做逐字比对，发现改字即判 `failed`）。
3. **不保留来源与编辑标签**：自动剥离 `https?://...` 链接行与 `#作者#` 署名标签，避免配音时误读网址。

---

## 三、`ruby_pairs.json` 补漏格式

当 `prepare` 返回的 `candidates.json` 中存在 `unresolved_misses`（多为汉字与假名混写的作品名或带假名的人名，例如 `月に寄りそう乙女の作法3`、`仰木サヤ`）时，在 `<run_dir>/ruby_pairs.json` 中补充键值对：

```json
{
  "月に寄りそう乙女の作法3": "Tsuki ni Yorisou Otome no Sahou 3",
  "仰木サヤ": "Ougi Saya",
  "深澤秀行": "Fukasawa Hideyuki"
}
```

也支持以对象列表形式传入：

```json
[
  {"surface": "仰木サヤ", "romaji": "Ougi Saya"}
]
```
