# Galgame 周报文风与说人话规范

## 一、核心原则：先“说人话”，再套骨架

写周报是写给玩家听、给配音（CV）念的资讯播报，不是写公文或机器翻译。必须做到**信息准、断句顺、说人话**：

| 常见 AI/机翻病句（禁止） | 怎么说人话（推荐） |
| --- | --- |
| 本作是一部以奇幻校园为背景、内容丰富、剧情引人入胜的冒险游戏，相信会给玩家带来沉浸式的体验。 | 别写空话！只写具体设定或卖点，例如：*本作讲述男主回到乡下老家、与青梅竹马重逢的日常恋爱故事*；没有具体内容就不编。 |
| 目前游戏正在锐意制作中，预定于2027年发售，敬请期待吧！ | 把日语直译和感叹号换成正常人话：*目前游戏仍在制作中，预计2027年发售，感兴趣的玩家可以先留意一下。* |
| 欢迎前往Steam商店页面将其添加至愿望单以获取最新动态资讯！ | 精简顺口：*感兴趣的玩家可以去 Steam 商店加个愿望单。* |
| 本周，某社公开了新作体验版，并公开了新CG，同时公开了主题曲PV。 | 别在同一段里连着重复动词：*本周，某社放出了新作《XXX》的体验版，还顺带更新了几张新CG和主题曲PV。* |
| 把主创、平台、价格、折扣、发售日全挤进一个 90 字长句。 | 拆成两三句短话，每句只交代一件事，让配音员一口气能念完、不用喘不过气。 |

### 语病检查与润色底线（有病才改，无病不乱改）
1. **避免重复**：同一条新闻内避免连用“公开了……并公开了……”、“宣布……并宣布……”，也不要两段重复车轱辘话。
2. **补充具体细节**：优先写清制作团队（原画/剧本/声优/歌姬）、平台、版本和具体变更点；没披露的次要细节直接省略，不写废话凑字。
3. **用词严谨、数字不出错**：严格区分“开启预约 / 公开商店页”和“正式发售”，区分“英文版”和“官中”；发售日、价格、折扣比例、税别必须和来源对上。
4. **不做无效改写**：句子本身已经通顺准确、有实质内容时，不要为了改而改去替换同义词。

## 二、栏目划分与公式化骨架（填实之后顺成口语）

周报固定沿用三个栏目，按以下顺序排列：

1. **新作**：PC/主机新作发表、官网公开与更新（CG/CV/OP/背景/试听）、体验版、制作完成、开启预约/发售日决定、正式发售、延期、主机移植以及当月新作发售汇总。
2. **汉化**：官中公布、支持简繁中文的 Steam/DLsite 商店页面公开、官方中文化补丁、海外发行消息（注意：仅出英文版且无中文支持证据时，只能写英文版/国际版，严禁写官中）。
3. **周边**：抱枕套、立牌、徽章、设定集、OST、联动咖啡厅、快闪店、线下展会、音乐会、众筹活动。

### 三类新闻常用骨架（参考槽位，按实际事实自然增删）

#### 1. 新作模板骨架
- **常规四层**：`本周新变化 → 必要作品背景（前作/原画/剧本/原版发售日） → 发售/预约/平台信息 → 简短引导语`
- **常用句式参考**：
  - 正式发售：`本周，{会社名}宣布《{作品名}》正式发售，本作是{前作/系列关系简述}，由{原画师}负责原画，{剧本作者}负责剧本，目前已在{平台}上线。`
  - 官网与更新：`本周，{会社名}公开了新作《{作品名}》的官网，并放出了{新CG/OP动画/角色语音等}。游戏将于{日期}开启预约，预计{发售日}发售，感兴趣的玩家可以去官网看看。`
  - 体验版：`本周，{会社名}在《{作品名}》的官网（或 Steam 商店页）放出了体验版，包含游戏早期流程内容，感兴趣的玩家可以先下载试试。`
  - 延期公告：`本周，{会社名}宣布原定于{原定日期}发售的《{作品名}》推迟至{新日期}发售。目前游戏仍在制作中，感兴趣的玩家可以留意后续消息。`

#### 2. 汉化模板骨架
- **官中登陆 Steam**：
  `本周，由{制作方}制作的《{作品名}》登陆 Steam 平台，由{发行方}代理发行并支持官方中文。本作是一部{一句话讲清题材/卖点，不编造}，由{主创}负责{剧本/原画}。游戏国区售价{售价}，{促销折扣信息}，感兴趣的玩家可以去商店页面看看。`
- **民间汉化发布**：
  `《{作品名}》是由{制作方}于{原版发售日期}发售的{题材类型}作品，本周迎来了民间汉化。本作由{主创}负责{剧本/原画}，感兴趣的玩家可以了解一下。`

#### 3. 周边模板骨架
- **周边商品开订/发售**：
  `本周，{公司名}宣布推出《{作品名}》的{周边类型}，并在{渠道/平台}开启预约。{材质/款式等关键卖点}，售价为{价格及税别}，预计{出货/发售日期}发货，感兴趣的玩家可以前往对应页面查看。`
- **线下活动/联动/快闪店**：
  `本周，{公司名}宣布将举办《{作品名}》的{活动名称}，活动将于{活动日期}在{地点}举行，届时将贩售{商品类型}等限定周边，感兴趣的玩家可以留意一下。`

## 三、清理与导出红线

1. **去除残留日文宣传语与表情**：推文中的颜文字（`🤣`、`✨`、`🎉`）、抽奖口令（`フォロー＆RP`）、日文口号（`ぜひお楽しみに！`）一律清除或译成自然中文；仅作品原名、会社名、人员名和曲名保留原名。
2. **禁止虚构署名与批注**：`周报初稿.docx` 统一采用 **15 磅加粗标题 + 11 磅常规正文**，绝不添加 `#作者#` 标签或编辑批注。
3. **日文注音由独立技能 `weekly-ruby` 负责**：本技能生成的 `周报初稿.docx` 与 `口播稿.md` 均保持纯净无 `【】` 注音；需要配音注音时再将任意一稿输入 `weekly-ruby` 生成 `口播注音稿.md`。


## 五、基于第 259—267 期人工成稿对比的精修规范

1. **标题精简准则（单句单重心，禁用逗号与双谓语并列）**
   - 人工成稿标题严格遵循“**作品/厂商主体 + 单一核心动作**”，字数通常控制在 12—22 字以内，不使用逗号，也不写“公开A并宣布B”、“同步开启预约”等双谓语复合长句。
   - **推荐写法**：
     - `《Happy Weekend》体验版公开`
     - `《覗怪》官网公开`
     - `《同级生2 Remake》将登陆 Steam 并支持官方中文`
     - `MAGI ARTS宣布制作《Anemoi》辻倉朱比華手办`
     - `CUFFSの秋通販 2026开启`
     - `《爱上火车-Last Run!!》开启线上抽奖活动`
   - **避免写法**：
     - `AirVelocity主机版《Happy Weekend》制作完成并公开角色视频`
     - `MAGES.新作《覗怪》公布发售日与声优阵容，同步开启预约`
     - `《さくらの雲＊スカアレットの恋》官宣登陆Steam与JAST，确认支持官方中文`

2. **作品名称本地化与常用名优先级**
   - 若作品拥有广为人知的官方中文名、通行译名或官方英文名，标题与正文中优先采用中文译名或英文标题（必要时可在正文首提时括注日文原名）：
     - 例：优先写 `《夏日终焉》`（而非仅写 `《夏ノ終熄》`）、`《咲夜叙-妖刀的约定-》`（而非 `《サヤガタリ -妖刀の約束-》`）、`《战国兰斯》`（而非 `《戦国ランス》`）、`《樱花云＊绯红恋》`、`《甜蜜女友3》`、`《爱上火车-Last Run!!》`、`《白日梦的构想图》`、`《One Night After》`（而非 `《ワンナイトアフター》`）、`《LimeLight Lemonade Jam》`（而非 `《ライムライト・レモネードジャム》`）。

3. **起笔与收尾统一范式**
   - **统一以“本周，”起笔**：除“民间汉化发布”（以 `《作品名》是{厂商}于{年份}发售的Galgame...` 起笔）和“X月新作本周发售”外，其余所有新闻正文首句统一以 **`本周，{品牌/厂商/社团}...`** 起笔。**严禁在段首使用 `9月28日，`、`10月2日，` 等具体日期起笔**（具体日期仅用于正文内部交代未来的发售日、预约截止日或活动起止时间）。
   - **克制统一的收尾引导语**：统一使用 `感兴趣的玩家可以前往官网了解详情。`、`感兴趣的玩家可以持续关注。`、`感兴趣的玩家可以前往 Steam 商店页面将本作加入愿望单 / 购买支持。`，避免编写抒情式或花哨的宣传结语。

4. **各栏目必填要素核对表**
   - **月末发售汇总（`《X月新作本周发售》`）**：当周覆盖当月最后一个周五时，固定置于「新作」第一条。导语固定为：`X月新作已于本周发售，一共有N部作品，其中 PC 平台有M部作品，主机平台有K部作品，具体的游戏如下所示：`，随后逐行按 `《作品名》（PC/NS）品牌名` 排列。
   - **常规 CG / 官网小更新（两句短讯模板）**：控制在 120—160 字，第一段写 `本周，{品牌}在新作《{作品名}》的官网上更新了{N}张CG（或角色试听语音/背景图像），感兴趣的玩家可以前往游戏官网了解详情。`；第二段写 `本作由{原画}负责原画，{剧本}负责剧本。游戏目前正在接受预约，预计于{发售日}发售。`
   - **汉化栏必填项**：必须写明 **原作开发商与原版发售年月**、**原画与剧本主创**、**支持语言（简中/繁中/英/日）**、**Steam 国区人民币售价及首发折扣价（如“售价 88 元，首发优惠价 68.64 元”或“锁国区 / 发售日暂未公开”）**。
   - **周边栏必填项**：
     - **通贩 / 快闪店 / 联动咖啡厅**：必须写明**商品或餐点品类**、**含税价格区间（`价格从 XXX 日元至 XXXXX 日元不等（均含税）`）**、**满额或点单特典门槛（如“单笔消费每满 3000 日元随机获赠 1 款特典小卡”）**、**活动或预约起止日期**及**预计发货/出货月份**。
     - **手办 / 玩偶**：写明**出品厂商**、**角色名与比例（如 1/6、1/7 或坐姿玩偶）**、**含税售价**、**预约截止日与预计发售年月**（若仅为企划发表，写明比例后以“目前更多信息尚未公开，感兴趣的玩家可以持续关注”收尾）。
     - **付费线上抽赏（オンラインくじ）**：写明**抽赏平台与作品**、**等级设置（如 S 赏至 E 赏共五个等级）**、**奖品内容**、**中奖概率区间（如 1.5% 到 50.5% 不等）**、**单抽含税价格**及**活动起止日期**。
